## 只读接口

`GET /api/bills/monthly?month=2026-01&account_id=1`，需 `Authorization: Bearer <登录令牌>`。`month` 可省略，默认北京时间当月；提供时必须为 `YYYY-MM`。`account_id` 可省略，仅在用户恰有一个可用账户时自动选择；多账户需指定。只查询登录用户的可用账户，接口不返回卡号明文或账户引用。响应含 `Cache-Control: no-store`。

示例字段（金额均为整数分）：

```json
{
  "month": "2026-01", "account_name": "演示活期账户", "masked_number": "**** 0001", "currency": "CNY",
  "income_fen": 600000, "expense_fen": 100000,
  "consumption_fen": 100000, "consumption_count": 2,
  "transfer_out_fen": 0, "transfer_out_count": 0, "transfer_in_fen": 0, "transfer_in_count": 0,
  "categories": [{"category": "餐饮", "amount_fen": 50000, "count": 1}, {"category": "购物", "amount_fen": 50000, "count": 1}],
  "anomalies": [], "ignored_count": 0
}
```

以上为种子数据示例。空月返回金额和笔数为零、分类和异常为空数组。错误月份、不可用或不属于当前用户的账户、多账户未指定分别返回 400 和中文提示；无效登录返回 401。不得使用返回数字自行推断账户所有权。

## 统计口径

- 时间为北京时间自然月 `[月初，下月月初)`，查询整月全部流水；日期在存储中按 UTC 处理。
- 所有收入和支出计入总收入、总支出，转入转出也分别统计；模拟转账不计入消费分类。转账依据关联的模拟转账记录或类别 `模拟转账` 识别；其余支出视为消费。
- 分类合计为消费金额；未知流水方向不计入收支，`ignored_count` 为其笔数。分类和商户名称经保守遮盖。
- 同账户、同一自然月内，同商户同金额消费相隔不超过 10 分钟，后一次列为 `需核对`，返回脱敏商户、金额及两次北京时间。仅是重复消费提示，不代表已确认欺诈；转账不参与该规则。
- `get_monthly_bill` 为绿色只读工具，接受可选 `month` 和 `account_token`；引用由 Vault 校验用户、类型、有效性和账户状态。对话结果由后端固定格式渲染。直接接口和对话各记录工具审计，不保存参数或敏感数据。

对话演示输入：

1. “分析 2026 年 1 月的消费。”
2. “看看这个月的收入和支出。”
3. “这个月有没有需要核对的重复消费？”
