## 产品与约束

产品以 Agent 对话为主，资产工作面、收藏和操作记录辅助。界面避免重复次级说明、保持视觉对齐，拖拽和转换追求跟手弹簧；金额与业务状态以服务端为准。隐私显示仅遮盖已接入的结构化内容，不覆盖任意对话文字，也不是安全边界。

开发强调可维护性与验证，不通过假成功、无条件重试、自动切换样例数据或任意生成代码填补后端缺口。提交、推送、PR 需另行授权。

## 当前实现

- 2026-10-29 本轮恢复：增加共享工作区与导航框架，正式对话和开发专用 `/product-preview` 共用外壳、工作面框架、会话侧栏、消息、输入框、卡片渲染和收藏面板。宽屏初始显示资产工作面，手机通过入口切换。预览使用合成内容，不挂载正式鉴权、不调用业务接口；预览收藏使用独立 IndexedDB 名称，不能与正式收藏混用。资产内容仍与正式界面不同，不能视为完成统一产品视图。
- 合成预览提供多个账户与联系人之间的点击或长按拖动组合、详情及返回对话的本地胶囊；确认样例依据当前选择展示对象，并标明金额也是样例。有三种结构化卡片及共享确认弹窗中的本地模拟验证、执行反馈，并提供正常、空和错误样例状态。服务端尚不支持前置意图绑定或此处展示的结构化事件，预览不代表真实业务支持；这些手势与模拟确认已有浏览器测试，尚未进行真实手机手感验证或真实服务联调。
- 登录表单不预填账号或密码，字段具有可见标签，失败提示可被辅助技术读取；移除了未经验证的安全承诺。用户自行处理真实登录。对话与预览复用阅读位置逻辑，预览结果按关联消息显示，避免后续消息出现后卡片被移动到对话末尾。
- 对话的会话、草稿和流接收从页面抽离到控制层；鉴权会话变化时重新创建私有界面。页面卸载会停止浏览器流接收并忽略迟到结果，这不代表服务端任务已经取消。健康状态请求失败时不会持续显示“连接中”；账单注明本机查询时间。
- 待处理动作或卡片挂失准备期间，暂时禁止切换和新建会话并说明原因，避免把动作显示在另一个会话上下文中；这不是跨会话动作恢复方案。

- 对话支持会话与草稿、阅读位置保护、SSE 分片解析、断流和异常提示。接收流时可停止浏览器接收，界面说明服务端可能仍在处理；已接收片段保留。新建会话期间继续输入的内容留在原会话，首次发送等待创建时新增的输入也会保留。手机侧栏关闭时从布局隐藏，打开后聚焦关闭按钮，支持 Escape 并返回原焦点。切换会话时清除旧消息，历史加载失败可重试且暂不允许发送；加载历史期间暂不新建会话。已收到的完成消息在历史回读暂时缺项时保留，并提示不一致。待确认动作在当前页面内存中保留，确认、模拟验证和执行分开；转账缺少账户、收款人、金额或币种不受支持时禁止继续；刷新不能恢复一次性凭证。
- 资产面板接入银行卡列表、模拟挂失准备和账单只读查询；银行卡与审计列表在接口边界校验字段及标识，格式异常显示错误。工作面打开后聚焦返回入口，主动关闭或使用 Escape 时回到原焦点。操作记录接入现有增序分页，区分已知工具与事件，并可展开已有的关联编号。刷新后会忽略此前尚未完成的分页结果，分页失败保留已加载记录。挂失结果未知时不自动重试；用户可明确用同一幂等键核对，键随 Chat 保存在当前页面内存，待处理且无凭证时只允许取消；挂失完成后重新查询卡片状态。
- 账单再次查询失败时保留此前成功的结果并标明其为上次查询；查询与收藏进行中不能相互覆盖，新账单成功后重新允许收藏。该行为已用组件测试验证，尚未经过真实后端联调。
- 受控卡片支持文本、指标、明细、图表、有限分组及白名单导航；收藏只保存显式选择的本地静态快照，按用户标识区分，不保存动作入口。收藏使用列表与详情，损坏记录仍可查看提示和删除，返回与删除后恢复焦点。快照可选保存由调用方单独提供且格式已校验的会话／消息引用，忽略卡片描述中自行声明的引用；格式校验本身不证明关联真实性，正式适配需要后端确认归属。已有引用时可回到会话，但尚不能定位具体消息，也不能代表后端已有结构化历史协议。收藏面板用户变化时重新建立界面状态，避免旧用户的内容或迟到操作影响新列表。当前字符串脱敏只是有限规则，可能保留敏感文字，保存入口和收藏页已提示这一限制。账单不指定账户时，后端仅在恰有一个可用账户时自动选择。
- 开发预览提供合成数据及意图组合样例，不连接业务写接口。真实前置意图绑定、联系人和持仓接口尚未实现，样例不能视为已联调能力。
