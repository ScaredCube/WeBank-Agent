# T-205 受限计算工具

状态：后端完成。2026-10-29 运行 `tests/test_calculator.py` 30 passed，完整后端回归 140 passed；未调用付费模型。

## 目标

为 Agent 提供一个只做数值计算的绿色 Tool，避免模型口算或编造计算结果。它不是代码执行环境，不提供变量、函数、属性访问、导入、容器或控制流能力。

## Tool 契约

- 名称：`calculate`
- 风险等级：绿色，自动执行
- 参数：`{"expression": "<纯数学表达式>"}`
- 表达式规则：数字、括号、一元 `+/-`、二元 `+ - * / // % **`
- 成功结果：`{"result": <int|float>, "kind": "int"|"float"}`
- 固定渲染：`计算结果：<格式化数字>`，由后端根据 Tool 返回值生成，不采用模型自由文本
- 审计：通用 `tool_called`、`risk_assessed`（green）、`tool_result`，工具名 `calculate`

## 安全限制

| 限制 | 值 / 行为 |
| --- | --- |
| 表达式长度 | 最长 200 字符 |
| AST 节点数 | 最多 100 |
| 单次求值时限 | 50 ms，递归求值每步检查截止时间 |
| 整数位长 | 最多 512 bit |
| 浮点绝对值 | 最多 `1e15`，且必须有限 |
| 指数绝对值 | 最多 64 |
| 除零 | 拒绝，返回“除数不能为零” |
| 非数值节点 | 变量、函数调用、属性、下标、容器、条件表达式、lambda、导入等全部拒绝 |
| 布尔 / 复数 / 字符串 / None | 拒绝 |
| 溢出 / 非有限值 | 拒绝，返回“结果超出范围” |

求值器直接遍历 Python `ast`，不使用 `eval`。先解析并检查长度、节点数，再递归求值；每次运算后检查数值范围，避免超大整数或浮点结果。

## 错误处理

固定中文错误：

- `表达式无效或过长`
- `表达式无效`
- `表达式过于复杂`
- `仅支持数字和基本运算`
- `除数不能为零`
- `指数过大`
- `结果超出范围`
- `计算失败`
- `计算参数无效`

错误信息不包含表达式原文、内部异常或调用栈。

## 边界

1. 计算器只处理数值，不处理货币单位、百分比或业务口径；金额换算仍由对应 Tool 和服务端固定代码完成。
2. 时限是协作式截止检查，不是独立进程或沙箱，不会强杀线程；由于表达式长度、节点数、指数和数值范围均受限，实际求值有界。
3. 浮点运算存在精度误差；涉及金额时应优先使用整数分和整数运算。
4. 计算器不读取账户、交易或用户数据，也不写数据库。
5. 模型仍可能尝试自行口算；系统提示词要求需要算术时调用 `calculate`，但最终防编造依赖固定渲染、Tool 白名单和后续审计 / 护栏。
