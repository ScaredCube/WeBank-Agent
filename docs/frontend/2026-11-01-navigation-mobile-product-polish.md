## 目标与实现

基于五张实际页面截图及后续设计参考，修复产品体验与开发预览不一致的问题。

1. **开发预览与正式产品分离**：`/product-preview` 仅是 DEV 下的交互样例，不接入银行 Agent。默认不显示“合成预览”顶部气泡和手机横幅；状态调试工具仍可用 `?debug=1` 调出。演示的银行卡仍明确标为“模拟银行卡”，不把合成资金数据冒充实际账户。正式业务使用带鉴权的 `/chat`。
2. **预览资产页签真实切换**：曾经全部渲染、依靠滚动定位的 `PreviewAssets` 改成和正式 `AssetWorkspace` 一致的五分类视图。导航本身吸顶；卡面/联系人交互只在当前分类展示。账单分类在纯预览中明确引导去对话，不伪造账单服务。
3. **手机资产操作**：鼠标精确指针的桌面端才启用引用拖拽；触摸屏改为点击账户选择和“询问”引用。原预览的长按拖动提示在手机隐藏。详情按钮与询问入口分列，删除“样例卡片状态：正常”等重复说明。
4. **银行卡卡面**：正式 `AssetWorkspace` 的银行卡从普通白色信息框调整为深绿色卡面，保留脱敏尾号、状态、挂失操作和可引用到对话的操作。
5. **最近对话管理**：统一侧栏实现按时间分组、标题搜索、列表内新建、管理菜单与真实重命名。菜单与会话选择使用独立可访问按钮，不嵌套交互元素。新端点 `PATCH /api/chat/conversations/{conversation_id}` 校验登录人对会话的所有权；只更改标题，不重写消息、可信结果、金融操作或幂等记录。预览的重命名仅修改示例内存。
6. **会话切换**：复用已有 `useChatController` 历史请求序列号与草稿隔离逻辑；新增侧栏的管理按钮不触发历史切换，避免原来出现的错位交互。

## 安全边界与未完成部分

- **暂未引入删除会话**：关联记录包括加密银行结果、请求去重及可能的待确认操作。删除策略需要在独立代码质量审查中确定保留范围、授权条件及审计要求后再开发，避免级联误删。
- 收藏仍是本机浏览器 IndexedDB，符合上轮资产约定；跨设备同步未开发。
- 改动不重新部署或替换团队的 `8000/5189` 常驻服务；当前独立功能工作树尚未推送或合并。
- 视觉参考中的完整账户详情独立页面尚未实现；现有详情展开保留，当前主修复集中在导航、操作反馈、文本与卡面视觉一致性。
