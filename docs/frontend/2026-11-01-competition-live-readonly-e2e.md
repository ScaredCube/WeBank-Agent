### 显式执行

```powershell
cd backend
uv run --group dev python scripts/run_competition_e2e.py --live --evidence-dir "D:\competition\深圳国际金融创新大赛\远程工作空间\UX验收_2026-11-01_第二十二批比赛集成"
```

`--live` 是显式外部模型 API 调用许可；默认缺少标志时脚本直接拒绝运行。后端仅从现有 `.env` / 环境获取供应商 API Key，脚本不会读取、输出或持久化模型密钥。每次脚本只使用生成的全新 SQLite 数据库，不会迁移或写入团队已有数据库；服务仅绑定 `127.0.0.1`，并严格检查两个独立端口没有被占用。异常结束也会终止本次启动的服务；Windows 临时文件句柄释放前执行有限次数清理重试。

## 交易确认的明确边界

本批真实模型浏览器联调严格限于**只读金融操作**，不会让自动化脚本接收一次性确认凭证并自动执行模拟转账。交易准备、确认和执行的安全规则由第 20–21 批已有的隔离后端业务测试验证，包含确认前不扣款、单次令牌、相同操作幂等与跨进程故障后的账务一致性。

因此目前**不能**宣称「真实模型 + 真实浏览器完整转账授权」已通过。这一完整体验需要另行组织有明确人工点击授权边界的演示验收，并检验跨刷新后待确认操作的产品可恢复性。
