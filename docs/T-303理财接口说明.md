# T-303 模拟理财接口

状态：后端已实现并通过测试，前端按人工要求暂不接线；全部产品、持仓、收益和风险测评均为模拟数据，不对接真实银行或真实理财。

## 1. 接口分层

银行数据只读接口（供前端负一屏和服务层封装使用，不注册为 Agent Tool）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/bank/wealth/products` | 可申购模拟产品列表，返回 `product_id`、名称、类别、风险等级、参考年化、期限、起购金额 |
| GET | `/api/bank/wealth/holdings` | 当前用户模拟持仓，返回 `holding_id`、`product_id`、持仓金额、昨日收益 |
| GET | `/api/bank/wealth/risk-profile` | 当前用户风险测评结果 |

这些接口只返回实体 ID 和脱敏展示字段，不返回数据引用令牌、卡号明文或手机号明文，也不记录 Tool 审计。LLM 不能直接调用这些 HTTP 接口；Agent Tool 直接调用 `wealth_service`，不经过 HTTP。

Agent 业务操作接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/wealth/risk/assess` | 提交 3 道固定题的答案，服务端计算风险等级；不注册为 Tool |
| POST | `/api/wealth/subscribe/prepare` | 创建红色模拟申购动作，首次返回一次性令牌 |
| POST | `/api/wealth/redeem/prepare` | 创建红色模拟赎回动作，首次返回一次性令牌 |
| POST | `/api/wealth/orders/{order_id}/execute` | 模拟验证通过后执行并更新余额、持仓和流水 |

所有接口需要 Bearer 登录令牌，受用户级限流和锁定约束；成功响应带 `Cache-Control: no-store`。

## 2. Tool

绿色只读：

- `get_wealth_products`：返回产品字段和用户级 `product_token`。
- `get_wealth_holdings`：返回持仓字段和用户级 `product_token`。
- `get_wealth_risk_profile`：返回风险等级、分数和测评时间。

红色准备：

- `prepare_wealth_subscribe`：参数 `product_token`、`amount_fen`、可选 `account_token`、`note`。
- `prepare_wealth_redeem`：参数同上。

红色 Tool 只创建待验证动作，返回 `action_required` 事件；令牌只交给客户端，不写入模型消息、会话历史或日志。验证和执行必须由客户端调用独立接口完成。

## 3. 风控与执行

- 申购与赎回均为红色，必须完成服务端模拟验证；`DEBUG=false` 时整个红色流程拒绝执行。
- 申购要求账户正常、币种 CNY、余额充足、关联卡片正常、金额不低于产品起购金额。
- 赎回要求账户仍正常、持仓充足；赎回金额不能超过当前持仓。
- 申购扣减账户余额并增加持仓，流水类别为 `理财申购`；赎回减少持仓并增加账户余额，流水类别为 `理财赎回`。
- 持仓减至 0 时状态为 `redeemed`，再次申购会把同一持仓恢复为 `active`。
- 执行在 SQLite `BEGIN IMMEDIATE` 事务内重查账户、卡片、持仓、产品状态和验证有效期；审计失败时整体回滚。
- 同一用户 `idempotency_key` 唯一；重复准备不返回令牌，重复执行返回首次结果。
- 已挂失卡片会阻止申购，但不阻止赎回入账。

## 4. 风险测评

`POST /api/wealth/risk/assess` 接收 3 个 0–3 的整数答案，服务端求和：

| 分数 | 等级 |
| --- | --- |
| 0–2 | R1 |
| 3–5 | R2 |
| 6–7 | R3 |
| 8–9 | R4 |

风险测评是固定演示逻辑，不是真实投资者适当性评估；产品列表只展示风险等级和参考年化，不构成投资建议。

- 产品、收益和持仓均为模拟数据，不构成投资建议；没有真实产品净值、费率、封闭期和收益结算。
- 仅支持 SQLite。
- 前端尚未接线，`action_required` 中的 `order_id` 和令牌需要后续前端重构时消费。
- 通用 Tool 事务与幂等规范（T-206）尚未完成，当前事务边界由理财服务自身保证。
- 多账户仅在服务端支持指定账户；演示种子仍为单账户。
